## 구성 요소

### 1. 패널 헤더

```
‹  일정 조율    [✨ AI 맞춤 추천]    접기 ×
```

- `‹` 뒤로 / `접기 ×` 패널 닫기 (둘 다 `roomOverlay = null`)
- `[✨ AI 맞춤 추천]` 녹색 버튼 → **07 문서의 AI 추천 일정 후보 TOP 3 전체 화면** 오픈

### 2. 그리드 탭 (`ScheduleGrid.tsx:3970~3987`)

| 탭 | 값 | 설명 |
|---|---|---|
| 내 일정 | `'my'` | 본인 가용 시간 **편집 가능** |
| 모두의 시간 | `'group'` | 참여자 겹침 히트맵 (읽기 전용) |
| 연동 | `'calendar'` | 기기 캘린더 연동 뷰. 전역 모드(`isGlobal`)의 기본 탭 |

- 편집은 `!isConfirmed && activeTab === 'my' && !isCoordination` 조건에서만 허용 (`ScheduleGrid.tsx:2104`)
- **약속이 확정되면 그리드가 읽기 전용으로 잠김**

### 3. 시간 그리드

- 제목: `약속 당일 시간표 조율` (하루) / `7일간 시간표 조율` (여러 날) — `ScheduleGrid.tsx:3618`
- 세로축: **30분 단위 슬롯**, 영상 확인 범위 `11:30 ~ 22:30`
- 가로축: 날짜 (하루 모드면 1열)
- 칠하기: **터치 후 드래그로 연속 슬롯 일괄 선택** (`onStartShouldSetResponder` / `onMoveShouldSetResponder`)
- 색상: 녹색 = 가능. `모두의 시간` 탭에서는 겹치는 인원 수에 따라 농도가 달라짐 (`intensity`)
- 저장 형식: `ScheduleAvailability` = `{ "2026-07-25": ["15:30", "16:00", ...] }`

- `ScheduleGrid.tsx:4167` — 방 모드에서는 `AI 추천 약속 시간`, 전역 모드에서는 `AI 추천 약속 날짜 (일정이 없는 날)`

## 코드에서 확인한 상세 (영상 미노출분)

### 그리드 시간 범위 — 확정

`ScheduleGrid.tsx:390` / `aiRecommender.ts:67` (동일 배열이 두 곳에 중복 정의)

```
09:00 09:30 10:00 10:30 11:00 11:30
12:00 12:30 13:00 13:30 14:00 14:30
15:00 15:30 16:00 16:30 17:00 17:30
18:00 18:30 19:00 19:30 20:00 20:30
21:00 21:30 22:00
```

**총 27개 슬롯, 09:00 ~ 22:00 (30분 단위).** 영상에서 본 `11:30~22:30`은 스크롤된 일부였고, 실제 하단 끝은 `22:00`입니다.

⚠️ `ProfileSetup.tsx:105`에는 **다른 `TIME_SLOTS`** 가 또 있습니다 (11개, 점심·저녁대만):
```
11:30 12:00 12:30 13:00 13:30   17:30 18:00 18:30 19:00 19:30 20:00
```
같은 이름의 상수가 3곳에 서로 다른 값으로 존재합니다. 복원 시 단일 상수 모듈로 통합 필요.

**연동 완료 상태**

- `expo-calendar` 사용. 권한 요청 후 이벤트를 읽어 `calendarEvents`에 보관

- 이 탭은 `isCoordination`이 아닐 때만 렌더됩니다

### 확정 완료 배너 (`ScheduleGrid.tsx:3792`)

### 편집 잠금 조건


(`ScheduleGrid.tsx:2104`)
