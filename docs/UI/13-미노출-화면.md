## B. 메뉴 룰렛 (`MenuRecommendation.tsx`, 521줄)

방 참여자들의 알레르기·지병을 반영해 후보를 걸러낸 뒤 룰렛으로 메뉴를 정하는 화면.

```
┌──────────────────────────────────────────┐
│ ⚠️ 안심 지킴이 작동 중                     │
│ 모임 참여자들의 건강(지병, 알레르기)을      │
│ 고려하여 아래 음식이 자동 제외되었습니다.   │
│ [⚠️ 땅콩 알레르기] [🩺 저염식 대상]        │
├──────────────────────────────────────────┤
│ 건강/알레르기 안전 필터 적용        [ ●──]│
├──────────────────────────────────────────┤
│ 우유부단 필터 조건                        │
│ 💰 희망 가격대 선택                       │
│ [1만원 이하 💰][1만~2만원 💵]             │
│ [2만~3만원 💳][3만원 이상 💎]             │
│ 🍺 모임 목적 선택                         │
│ [식사가 우선! 🍚][술이 우선! 🍺][상관없음 🤷]│
├──────────────────────────────────────────┤
│              🎰 메뉴 룰렛                 │
│      N개의 후보 메뉴가 준비되었습니다.      │
│                  ▼                       │
│           ┌─────────────┐                │
│           │   (룰렛판)   │                │
│           └─────────────┘                │
│      [ 오늘 뭐 먹지? 돌리기 🎲 ]           │
│                                          │
│ 🏆 오늘의 추천 메뉴!                       │
│    삼겹살 회식 🥩                         │
└──────────────────────────────────────────┘
```

### 필터 3단계

**1. 가격대** (`PRICE_RANGES`)

| id | 라벨 | 범위 |
|---|---|---|
| `low` | 1만원 이하 💰 | ≤ 10,000 |
| `mid` | 1만~2만원 💵 | 10,001 ~ 20,000 |
| `high` | 2만~3만원 💳 | 20,001 ~ 30,000 |
| `premium` | 3만원 이상 💎 | > 30,000 |

**2. 모임 목적** (`ALCOHOL_PRIORITY`)

| id | 라벨 | 동작 |
|---|---|---|
| `meal` | 식사가 우선! 🍚 | `isForDrink === false`만 |
| `drink` | 술이 우선! 🍺 | `isForDrink === true`만 |
| `either` | 상관없음 🤷 | 필터 없음 (기본값) |

**3. 안심 지킴이** (`safetyCheck`, 기본 ON)

참여자 전원의 `personal_data.allergies` / `health_issues`를 합집합으로 모아, 해당 항목이 걸린 메뉴를 제외합니다.

|---|---|---|---|
| `peanuts` | 땅콩 | `diabetes` | 당뇨식 |
| `shellfish` | 갑각류 | `hypertension` | 저염식 |
| `fish` | 생선 | `stomach` | 위장장애케어 |
| `peach` | 복숭아 | `vegan` | 비건식 |
| `dairy` | 유제품 | | |

- 최대 **8개**까지만 룰렛에 올림 (`filteredItems.slice(0, 8)`)

## 복원 시 판단 필요

1. **`baemin` 화면을 살릴 것인가** — 455줄이 완성되어 있으나 진입 경로가 없고 API도 목업. 메뉴 투표라는 기능 자체는 `Room.voting_items` 스키마까지 잡혀 있어 되살릴 가치가 있음
2. **메뉴 룰렛 vs 메뉴 투표 중복** — 둘 다 "뭐 먹을지 정하기"인데 방식만 다름(룰렛 / 투표). 하나로 합치거나 역할을 나눌 필요
3. **다크 테마 잔재** — `MenuRecommendation.tsx` 전체 재스타일링
4. **알레르기 코드 불일치** — `foodData.ts`는 `wheat`/`crustaceans`/`seafood`, `MenuRecommendation`·`BaeminSurvey`는 `gluten`/`shellfish`/`fish`. **같은 개념에 다른 키를 씀** → 취향 게임(10 문서)에서 저장한 알레르기가 메뉴 필터에 매칭되지 않음. `ProfileSetup.ALLERGY_PRESETS`는 후자를 쓰므로 실제 저장값은 `gluten` 계열이고, `foodData.ts`의 `allergens`만 고아 상태
