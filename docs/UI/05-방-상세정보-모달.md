## 필드 정의

### 1. 제목 + 이름 변경

- 헤더에 방 제목, 우측에 `[이름 변경]` 버튼
- 누르면 인라인 입력창 + `[취소] [저장]`으로 전환 (t=284s)

```
┌──────────────────────────────┐
│ 하이|                        │   ← 인라인 편집
└──────────────────────────────┘
              [취소] [저장]
```

### 2. 초대 코드

```
초대 코드              VF4HLD  [공유]
```

- 코드는 **녹색 볼드**로 강조
- `[공유]` = 시스템 공유 시트 호출 (영상에서 결과 화면 미확인)

### 3. 약속 일시

```
약속 일시              2026-07-25
```

- 확정 전에는 날짜만, 확정 후에는 `2026-07-25 16:30` 형태로 시각까지 표시

### 4. 약속 장소

3가지 상태를 가집니다.

**(a) 미설정**
```
약속 장소
설정된 장소 없음          [장소 설정]
```

**(b) 편집 중** (t=131s, 136s)
```
약속 장소
┌──────────────────────────────┐
│ 젬스톤 사하점                │
└──────────────────────────────┘
[🔍 장소 검색]      [취소] [저장]
```
검색 시 결과 카드가 아래 붙음:
```
┌──────────────────────────────┐
│ 젬스톤 사하점                │
│ 부산 사하구 괴정동 1206-8    │
└──────────────────────────────┘
```

**(c) 설정 완료** (t=140s)
```
약속 장소
동아대학교 승학캠퍼스 (위도: 35.12, 경도: 128.97)   [장소 설정]
```

- ⚠️ **이슈**: AI 추천 장소로 확정한 경우 `젬스톤 사하점 (위도: undefined, 경도: undefined)` 로 표시됨 (t=127s). `AIRecommendation.recommended_place`(`PlaceRecommendation`)에 좌표 필드가 없어 `Room.latitude/longitude`가 채워지지 않음
- ⚠️ 좌표를 사용자에게 노출하는 형식(`(위도: 35.12, 경도: 128.97)`)은 정보 노이즈. 복원 시 숨기거나 지도 링크로 대체 권장

## 코드에서 확인한 상세 (영상 미노출분)

### `[공유]` 버튼 — 공유 텍스트 전문 (`App.tsx:2040`)

```
[밀챗] '{방제목}' 밀챗 방에 초대되었습니다! 🎉

📅 일정: {모임 기준일}
👥 현재 참여자: {N}명
⏱️ 초대 코드 유효시간: {유효시간}

초대 코드: {CODE}

👉 바로 입장하기 링크:
{inviteLink}

일정 조율과 메뉴 설문에 참여하세요!
```

- `Share.share({ message, title })` — OS 기본 공유 시트
- **딥링크 (초판 서술 정정)**

  기본값이 커스텀 스킴이고, **Metro 개발 서버에서 실행 중일 때만** `exp://`로 덮어씁니다.

  ```ts
  let inviteLink = `mealchat://join/${currentRoom.code}`;   // 기본값

  const scriptURL = NativeModules.SourceCode?.scriptURL || '';
  const match = scriptURL.match(/^https?:\/\/([^/]+)\//);
  if (match && match[1]) {
    inviteLink = `exp://${match[1]}/--/join/${currentRoom.code}`;  // 개발 중에만
  }
  ```

  프로덕션 빌드에서는 `scriptURL`이 `file://...jsbundle`이라 정규식이 매치되지 않아 `mealchat://`가 그대로 나갑니다. `app.json`의 `"scheme": "mealchat"`와도 일치합니다.

  **초판에서 "프로덕션에서 무효한 링크가 나간다"고 적은 것은 오류입니다.** 코드 주석대로 "테스트 편의용" 분기이며 정상 동작합니다.
- ⚠️ 공유 시트 제목이 `Bob-yak 초대: {방제목}` — 앱 이름이 **밀챗**인데 여기만 옛 이름 `Bob-yak`. 본문의 `[밀챗]` 접두사와도 불일치
- 본문 마지막 줄이 `일정 조율과 메뉴 설문에 참여하세요!` 인데, **메뉴 설문(13 문서)은 도달 불가능한 화면**입니다

### `[추방]` 확인 다이얼로그 (`handleKickParticipant`, `App.tsx:2861`)

```
┌─────────────────────────────┐
│         멤버 추방            │
│ 정말로 '장'님을 이 방에서    │
│ 추방하시겠습니까?            │
│      취소       추방         │  ← destructive
└─────────────────────────────┘
```

성공: `완료 / '장'님이 방에서 추방되었습니다.`
실패: `오류 / 멤버 추방에 실패했습니다.`

추방과 동시에 방 전체에 시스템 메시지가 삽입됩니다:
```
'장'님이 방장에 의해 추방되었습니다.
```
추방당한 쪽 화면은 04 문서 참조 (`알림 / 방장에 의해 방에서 추방되었습니다.`).

### 방장 판정 기준

`Room.owner_id`가 아니라 **참여자 중 `created_at`이 가장 이른 사람**을 방장으로 계산합니다 (`App.tsx:274`, `roomOwnerProfileId`). 상세는 03 문서 참조 — `owner_id`와 어긋날 수 있는 구조적 문제입니다.

### 권한 정책 (코드 기준)

| 액션 | 조건 |
|---|---|
| `[추방]` 버튼 노출 | 방장 && 본인 아님 (`App.tsx:4653`) |
| `방 삭제` / `방장 위치 넘기기` | 방장 && 멤버 2명 이상 |
| 이름·장소·색상 변경 | **권한 체크 없음 — 전원 가능** |

⚠️ 방 제목·장소·테마색은 아무 멤버나 바꿀 수 있습니다. 방장 전용으로 제한할지 결정 필요.
