6번의 실사용 확인(기기 2대 필요) 하나뿐이다.

PRD 갭 셋(이원화 캘린더·성인 인증·방 만료 기준)은 "지금은 안 만든다"로
이미 결정됐을 뿐 "영원히 안 만든다"는 아니므로, 다시 만들 계획이 생기면
그때 새로 논의 대상이다.

**막혀 있는 것**: Gemini 결제 미연결(그래서 AD 의 프롬프트가 실제로 결과를 바꾸는지
확인 못 함), Google Maps 키 제한(넘어가기로 함), 테스트 계정 삭제.

## 5. 작업 방법 메모 (이번 세션에서 값을 치른 것들)

1. **프레임 단위로 본다.** 스크린샷은 테스트 대상 위젯이 아니라 **여백이 이상한
   곳**부터 본다. AA 도 AE 도 빈 공간이 증거였다. 356장을 찍고도 놓친 이유가 이것.
2. **눈으로 원인을 단정하지 않는다.** AC-2 에서 "하단 인셋 문제"라고 잘못 진단해
   엉뚱한 수정을 넣었다. `onLayout` 한 줄이 추측 세 번보다 빨랐다.
3. **`adb shell input keyevent 111`(ESC)을 쓰지 않는다.** 키보드가 아니라 모달이
   닫히고, 앱이 백그라운드로 가서 이후 탭이 런처를 누른다.
4. **탭 전에 전체 해상도로 잘라 확인한다.** 0.32 축소본에서 좌표를 추정하면
   빗나간다(사용자의 개인 앱이 열린 적 있음).
5. **목록·어휘를 화면에 하드코딩하지 않는다.** 세 벌로 갈라져 같은 컬럼에 섞였다.
6. **Yoga 기본값은 치수 속성으로 덮이지 않는다.** `ScrollView` 는 `flexGrow: 1`
   을 달고 나오므로 `height: 60` 을 줘도 남는 공간을 먹는다. `flexShrink` 기본값
   0 때문에 넘친 AC-3 과 같은 부류다. **`<ScrollView>` 에 `height` 를 준 코드를
   보면 일단 의심한다.**
7. **"설계 결정이라 범위 밖" 이라고 적기 전에 재 본다.** AC-4 를 그렇게 적고
   넘겼는데 실제로는 버그였고, 재 보니 한 줄로 고쳐졌다.
8. **여러 계정이 얽히는 기능은 코드만 읽어서는 못 잡는다.** 팔로우/친구
   추가처럼 "내 행동 → 다른 프로필이 내 목록에 나타난다"는 흐름은, 실제로
   두 번째 프로필을 팔로우해서 목록에 나타나는지까지 눌러봐야 드러난다
   (라운드 AO-1). RLS·뷰 조인처럼 타입 에러 없이 조용히 `null` 을 돌려주는
   종류의 결함은 `tsc`·`jest`(모킹된 supabase)로도 못 잡는다.

## 6. 환경

- 실기기에서 직접 빌드·실행하는 방법은 [BUILD_LOCAL_USB.md](../BUILD_LOCAL_USB.md)
  참고 (USB-C 연결, `npm run android`). `docs/BUILD_INSTRUCTIONS.md` 등은
  EAS 클라우드 빌드 기준이라 실제 작업 방식과 다르다.
- `.env` 는 gitignore 상태. 키를 모아둔 md 파일은 **사용자 요청으로 삭제됨**
- Supabase 마이그레이션은 사용자가 직접 적용한다. 하네스가 `db push` 를 막고,
  `!` 는 비대화형이라 `supabase login` 의 브라우저 흐름도 못 쓴다.
  **가장 확실한 경로는 대시보드 SQL Editor 에 붙여넣는 것**이다.
  (CLI 를 쓰려면 `npx supabase db push --db-url "postgresql://...pooler...:5432/postgres"`)
- ⚠️ **마이그레이션 파일이 운영 DB 와 다를 수 있다.** 실제로 `profiles_public`
  뷰가 파일과 컬럼이 달랐다(라운드 AL-7). 이력 테이블은 "적용됨"인데도 그랬다 —
  파일이 적용 후 수정된 것이다. **스키마를 바꾸기 전에 파일이 아니라 DB 에
  물어본다:**
  ```sql
  select ordinal_position, column_name from information_schema.columns
  where table_schema='public' and table_name='<뷰 이름>' order by 1;
  ```
- 규칙: **적용된 마이그레이션 파일은 고치지 않는다.** 바뀔 게 있으면 새 파일을 낸다.
- 푸시 알림은 트리거 → Edge Function → FCM → 기기까지 **동작 확인 완료**
