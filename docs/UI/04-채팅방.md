## 구성 요소

### 1. 방 헤더

```
‹  안녕 ▾   [⏰ 23시간 59분 52초 남음]
   멤버 2명 | 정보 확인 & 코드 공유 →
```

| 요소 | 설명 |
|---|---|
| `‹` | 뒤로 가기 → 방 목록(02). 스와이프 백도 지원 (`usePanResponderSwipeBack.ts`) |
| 방 제목 + `▾` | 탭하면 05 문서의 방 상세정보 모달 오픈 |
| 만료 카운트다운 | 빨간 배지. `⏰ HH시간 MM분 SS초 남음` — **초 단위 실시간 갱신**. `Room.expires_at` 기준 |
| 서브 라인 | `멤버 N명 | 정보 확인 & 코드 공유 →` — 이것도 상세 모달 진입점 |

- 카운트다운은 방마다 다름: 개설 직후 `23시간 59분 52초`, 다른 방 `476시간 15분 50초`, 확정 후 `28시간 20분 44초` → 확정 시 만료 시각이 **약속 시각 기준으로 재계산**되는 것으로 보임

### 2. 방 나가기 버튼

```
┌──────────────────────────────────────────┐
│              🚪 방 나가기                 │
└──────────────────────────────────────────┘
```

- 연분홍 배경(`danger` 계열 옅은 톤), 전체 너비
- 화면 최상단 눈에 띄는 위치에 배치되어 있음 — **오조작 위험이 있어 복원 시 위치 재검토 권장**

### 3. 공지 바

상태에 따라 문구가 바뀝니다.

| 상태 | 문구 |
|---|---|
| 조율 전 | `🔊 📢 [공지] 밀챗 약속 일정을 조율해 주세요!` |
| 확정 후 | `🔊 📢 [공지] 약속 확정! 🗓 2026-07-25 16:30` |
| 확정 후(요일형) | `🔊 📢 [공지] 약속 확정! 🗓 7월 25일 (토) 17:00` |

- ⚠️ 확정 공지의 날짜 포맷이 두 가지로 섞여 있음 (`2026-07-25 16:30` vs `7월 25일 (토) 17:00`) — 통일 필요

### 4. 서브탭 (패널 토글)

```
┌──────────────┬──────────────┐
│ 🗓 일정 조율  │ 💸 N빵 정산  │
└──────────────┴──────────────┘
```

- `App.tsx:3346~3362`, 상태는 `roomOverlay: 'schedule' | 'dutch' | null`
- **토글 방식**: 같은 버튼을 다시 누르면 닫힘 (`setRoomOverlay(roomOverlay === 'schedule' ? null : 'schedule')`)
- 활성 탭은 **주황색(`accent`) 채움**
- 열리면 메시지 영역 위에 인라인 패널이 확장됨 (모달 아님) → 06 / 08 문서

### 5. 메시지 영역

- **날짜 구분선**: `7월 25일 (토)` 중앙 정렬
- **내 메시지**: 우측 정렬, 녹색(`primary`) 말풍선, 흰 텍스트. 하단에 `오후 12:35` + `읽음 1/1`
- **상대 메시지**: 좌측 아바타(원형, `avatar_color`) + 이름 + 회색 말풍선 + 시각
- **이모티콘 메시지**: 말풍선 없이 이미지만 표시 (약 80x80)
- **시스템 안내**: `대화방이 개설되었습니다. 메이트들과 인사를 나눠보세요! 👋` — 중앙 정렬 `textMuted`
- 읽음 표시는 `읽음 N/M` 형식으로 **읽은 인원 수 / 전체 인원 수**

### 6. 입력 바

```
😊 [ 메시지를 입력해 주세요... ]      ➤
```

- 좌측 😊 = 이모티콘 패널 토글
- 우측 전송 버튼: **주황 원형**(`accent`)
- 포커스 시 한글 키보드가 올라오며 메시지 영역이 축소됨

## 실시간 동기화 (영상의 핵심 시연 포인트)

좌/우 두 화면이 동시에 갱신되는 것을 반복적으로 보여줍니다.

| 이벤트 | 좌측(방장) | 우측(메이트) |

| 참여자 입장 | `👋 장님이 입장했습니다` 배너, 멤버 수 +1 | `방 입장` Alert |

| 약속 확정 | 확정 Alert | `📌 약속 상태 변경` 배너 + 공지 바 변경 |

## 코드에서 확인한 상세 (영상 미노출분)

### 방 나가기 — 방장 여부에 따라 분기 (`handleLeaveRoom`, `App.tsx:2958`)

**일반 멤버**
```
┌─────────────────────────────┐
│        방 나가기 🚪          │
│ 정말로 이 밀챗 방에서        │
│ 나가시겠습니까?              │
│      취소      나가기        │  ← '나가기'는 destructive(빨강)
└─────────────────────────────┘
```
확인 시 `participants`에서 자기 행 삭제 → 로컬 키 `bobyak_part_id_{roomId}` 제거 → 방 목록으로 복귀

**방장이고 멤버가 2명 이상**
```
┌─────────────────────────────┐
│        방 나가기 🚪          │
│ 방장입니다. 나가기 전에 다른  │
│ 멤버에게 방장 위치를 넘기거나 │
│ 방을 삭제할 수 있습니다.      │
│   취소                       │
│   방 삭제        (destructive)│
│   방장 위치 넘기기            │
└─────────────────────────────┘
```
`방장 위치 넘기기` 선택 시 2차 Alert:
```
        방장 위치 이전
방장 위치를 이전할 멤버를 선택하세요.
   장
   철희
   취소
```
→ 멤버 이름이 Alert 버튼으로 나열됩니다. **멤버가 많으면 Alert 버튼이 과다해지는 구조** — 복원 시 목록 모달로 교체 권장

**방장이고 혼자일 때**: 일반 멤버와 동일한 단순 나가기 다이얼로그

### 메시지 알림 (`sendMessageNotification`, `notificationUtils.ts:69`)

