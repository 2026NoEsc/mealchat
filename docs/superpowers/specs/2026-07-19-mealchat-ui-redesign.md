# MealChat UI 전면 개편 설계 문서

**작성일**: 2026-07-19  
**프로젝트**: MealChat (밀챗) - 친구들과 함께 약속 정하고 정산하는 앱  
**목표**: 정보 위계 명확화 및 시각적 개선으로 깔끔하고 생동감 있는 UI 구현

---

## 1. 문제 정의 및 목표

### 현재 문제점
- 전체적으로 깔끔하지 못함
- 정보의 위계가 없어 사용자가 무엇을 해야 할지 불명확함
- 자잘한 네비게이션 구조로 인한 혼란

### 설계 목표
1. **정보 위계 명확화**: 카드 + 배지 시스템으로 한눈에 이해 가능하게
2. **시각적 개선**: 밝고 생동감 있는 디자인으로 사용성 향상
3. **핵심 플로우 강조**: 채팅과 메뉴 선정을 가장 접근하기 쉽게
4. **네비게이션 정리**: 직관적이고 일관된 상호작용 방식

### 핵심 사용 플로우
1. **주요**: 이미 정해진 약속에서 채팅 및 메뉴 선정
2. **부요**: 새로운 약속 만들기, 약속 채팅 확인

---

## 2. 설계 원칙

### 2.1 색상 팔레트

**배경 및 기본**
- 배경: 밝은 흰색 (#FAFAFA)
- 카드: 흰색 (#FFFFFF) + 부드러운 그림자 (둥근 모서리 16-20px)

**상태별 색상 (밝고 생동감 있게)**
- 메뉴 선정 필요: 주황색 (#FF8C42)
- 메뉴 선정 완료: 청록색 (#4ECDC4) 또는 민트 (#2FD89F)
- 일정 조율 진행: 파란색 (#5B9BD5)
- 확정됨: 보라색 (#9B59B6)

**텍스트 계층**
- 제목 (약속명): 크고 진한 검정색 (20-24px, 볼드)
- 부제목 (날짜/인원): 중간 회색 (14-16px, 중간 두께)
- 보조 정보 (상태): 작은 회색 (12px)

### 2.2 시각적 계층
- 충분한 패딩 (16-24px)으로 정보 분리
- 여백을 통한 명확한 영역 구분
- 색상 코딩으로 상태 한눈에 파악

## 3. 주요 컴포넌트

### 3.1 약속 카드 구조

```
┌────────────────────────────────────────────┐
│ [상태 배지]  약속명              [🔴 3]      │
│                                       (미읽)
│ 2024-01-15 (월) • 3명 참여                   │
│                                        │
│ 채팅 💬    메뉴 🍽️    일정 📅             │
│           미선정      조율중            │
│                                        │
│ [아이콘] [아이콘] [+1]                   │
└────────────────────────────────────────────┘
```

**구성 요소**:
1. **헤더**: 상태 배지 (색상 코딩) + 약속명 + 좌측 색상 사이드바 (3-4px)
2. **미읽 배지**: 우측 상단에 채팅 미읽 개수 (원형 배지, 빨간색)
3. **메타정보**: 날짜/요일 + 참여 인원 (한줄, 작은 텍스트)
4. **주요 액션**: 채팅, 메뉴, 일정 - 각각 아이콘 + 상태 배지
   - 채팅: 미읽 여부만 표시 (미읽 배지에 포함)
   - 메뉴: "미선정" 또는 "완료" 표시
   - 일정: "조율중" 또는 "확정" 표시
5. **참여자 프로필**: 프로필 색상 아이콘 (동그란 모양)

**상호작용**:
- 카드 클릭: 약속 상세 화면으로 이동 (채팅 탭 활성)
- 채팅/메뉴/일정 버튼: 각 탭으로 직접 이동

## 4. 화면별 레이아웃

### 4.1 메인 홈 화면 (약속 목록)

**상단 고정 영역** (높이: 56px)
- 좌측: MealChat 로고
- 우측: 프로필 버튼 + 알림 버튼 + 설정 버튼

**탭 네비게이션** (높이: 48px)
- "진행중인 약속" | "완료된 약속"
- 활성 탭: 색상 강조 (주황색) + 밑줄
- 비활성 탭: 회색

**카드 리스트**
- 스크롤 가능
- 각 카드 사이 여백: 12px
- 상하 패딩: 16px

**플로팅 액션 버튼 (FAB)**
- 위치: 우측 하단
- 텍스트: "+ 새 약속 만들기"
- 색상: 주황색 (#FF8C42)
- 크기: 56x56px (텍스트 있으면 더 클 수 있음)

**완료된 약속 탭**
- 카드 스타일: 회색톤으로 흐릿하게 표시
- 참고용 정보만 표시

### 4.2 약속 상세 화면 - 헤더

**헤더 영역** (높이: 80-100px)
- 좌상단: 뒤로가기 버튼
- 중앙: 약속명 (크고 진하게) + 날짜/시간
- 우상단: 설정/공유 버튼
- 하단: 약속 상태 배지 (색상 코딩)

### 4.3 약속 상세 화면 - 탭 네비게이션

**탭 3개**:
- 💬 **채팅** (기본 활성)
- 🍽️ **메뉴**
- 📅 **일정**

**스타일**:
- 활성 탭: 아이콘 + 라벨, 색상 강조
- 비활성 탭: 회색
- 밑줄 또는 배경색으로 현재 탭 표시

### 4.4 채팅 탭

**메시지 영역**
- 메시지 배경: 참여자 색상으로 구분
- 이모티콘: 크게 표시 (60x60px)
- 메시지 시간: 작은 텍스트로 표시
- 스크롤 가능, 최신 메시지부터 자동 스크롤

**참여자 정보**
- 채팅 상단 또는 우측에 참여자 목록
- 각 참여자: 프로필 아이콘 + 이름 + 온라인/오프라인 상태

**입력 영역** (하단 고정)
- 텍스트 입력 필드
- 이모티콘 버튼
- 전송 버튼 (활성: 주황색, 비활성: 회색)

### 4.5 메뉴 탭

**현황 표시**
- 상단: "메뉴 선정" 제목 + 진행 상황 (예: "3명 중 2명 선정 완료")
- 진행도 바 또는 텍스트로 표시

**AI 추천 섹션** (상단)
- 제목: "AI 추천 메뉴"
- 메뉴 카드: 이미지 + 음식명 + 추천 이유 (간단함)
- 투표 수 배지

**메뉴 카드 리스트**
- 이미지 (가로 16:9 또는 1:1)
- 음식명 (크고 진함)
- 투표 수 (원형 배지, 주황색)
- 투표 버튼 (크고 눈에 띄게, 미투표=흰색, 투표됨=색상)

**참여자별 선택 메뉴**
- 스크롤 가능한 리스트
- 각 참여자: 프로필 아이콘 + 이름 + 선택 메뉴
- 선택하지 않은 경우: 회색 텍스트 "선정 대기 중"

### 4.6 일정 탭

**현황 표시**
- 상단: "일정 조율" 제목 + 진행 상황 (예: "3명 중 2명 선택 완료")

**스케줄 그리드**
- 가로: 시간대 (예: 12:00, 13:00, 14:00...) - 30분 단위 또는 1시간 단위
- 세로: 참여자 (프로필 색상으로 구분)
- 셀:
  - 참여자가 선택 가능한 시간대: 해당 참여자 색상
  - 선택할 수 없는 시간대: 흐릿한 회색
  - 사용자 자신이 선택한 시간대: 더 진한 색상 또는 체크 표시

**확정 시간 강조**
- 가장 많은 사람이 선택한 시간: 굵은 선 또는 배경색으로 강조
- 예: 13:00-14:00에 3명 모두 참여 가능 → 강조

**정산 정보** (하단)
- 메뉴와 시간이 확정되었을 때만 표시
- "예상 비용: 1인당 ¥ 12,500"
- 더치페이 정보로 이동하는 버튼

### 4.7 새 약속 만들기 화면

**단계별 입력 (다이얼로그 또는 모달)**

**Step 1: 약속명**
- 입력 필드
- 플레이스홀더: "예) 회사 팀 점심"

**Step 2: 날짜**
- 날짜 선택 (달력 또는 텍스트 입력)
- 플레이스홀더: "2024-01-15"

**Step 3: 친구 초대**
- 친구 목록 (체크박스 + 프로필 카드)
- 선택된 친구: 체크 표시 + 강조색
- 검색 기능 (선택사항)

**하단 버튼**
- "만들기" 버튼: 크고 눈에 띄게 (주황색), 전체 너비
- "취소" 버튼: 흰색 배경, 주황색 텍스트

**진행도 표시** (선택사항)
- Step 1/3, 2/3, 3/3 표시

### 4.8 프로필 화면

**프로필 카드** (상단)
- 프로필 사진/아바타
- 이름
- 태그 (예: @john_doe)
- 프로필 편집 버튼

**음식 취향** (섹션)
- 아이콘 또는 칩 형식으로 표시
- 예: 🌶️ 맵기좋아 🍱 일식선호 🥩 육고기

**친구 목록** (섹션)
- 친구 카드: 프로필 + 이름 + 팔로우 상태
- "팔로우" 또는 "언팔로우" 버튼
- 친구 추가 버튼 (상단)

**설정** (섹션)
- 로그아웃
- 계정 설정
- 기타

### 4.9 정산 (더치페이) 화면

**현황 표시**
- 상단: "N빵 정산" 제목
- 정산 현황: "¥ 35,000 정산 필요" (진행 중인 건) vs "정산 완료" (완료된 건)

**정산 필요 리스트**
- 카드 형식
- 구성: 약속명 + 날짜 + 정산 금액 + 참여자 수
- 컬러:
  - 받아야 할 금액: 초록색 배경
  - 보내야 할 금액: 주황색 배경
- "자세히" 또는 "지불 완료" 버튼

**정산 상세 (클릭 시)**
- 누가 누구에게 얼마를 보낼지 명확하게
- 은행 정보 표시 (계좌 정보)
- "지불 완료" 버튼

## 5. 상호작용 및 네비게이션

### 5.1 하단 탭 네비게이션 (전체 앱)

**4개 탭** (또는 3개):
1. 💬 **약속 목록** (홈) - 현재 화면: 진행중/완료 약속 목록
2. 👥 **친구** - 친구 관리, 친구 검색
3. 👤 **프로필** - 사용자 프로필, 설정
4. (선택사항) 🔔 **알림** - 새 약속, 메시지 알림

**스타일**:
- 활성 탭: 아이콘 + 라벨, 색상 강조 (주황색 또는 테마색)
- 비활성 탭: 회색

### 5.2 화면 전환

**약속 목록 → 약속 상세**:
- 약속 카드 클릭 → 상세 화면 (채팅 탭 기본 활성)
- 채팅/메뉴/일정 버튼 클릭 → 해당 탭으로 이동

**약속 상세 → 약속 목록**:
- 좌상단 뒤로가기 버튼 클릭
- 또는 좌측에서 우측으로 스와이프 (iOS 스타일)
- 목록의 스크롤 위치 기억

**홈 → 새 약속 만들기**:
- 플로팅 액션 버튼(FAB) 클릭
- 또는 상단 탭에서 "+" 버튼

### 5.3 실시간 업데이트

**카드 업데이트**:
- 미읽 채팅 수: 실시간 반영
- 상태 배지: 메뉴 선정 완료 시 색상 변경
- 일정 확정 시 배지 업데이트

**애니메이션**:
- 카드 상태 변화: 부드러운 색상 전환 (200-300ms)
- 메시지 수신: 배지 팝업 애니메이션
- 탭 전환: 부드러운 슬라이드

### 5.4 네비게이션 정리

**피해야 할 것**:
- 깊이 있는 중첩 모달
- 혼란스러운 플로우
- 불명확한 버튼 라벨

**원칙**:
- 최대 2단계 깊이 (홈 → 약속 상세 → 채팅)
- 항상 뒤로가기 버튼 제공
- 현재 위치 명확하게 표시 (탭, 헤더)
- 주요 액션은 큰 버튼으로 강조

## 6. 기술 구현 가이드

### 6.1 색상 정의 (CSS/React Native)

```javascript
const COLORS = {
  // Backgrounds
  background: '#FAFAFA',
  cardBackground: '#FFFFFF',
  
  // Status colors
  menuNeeded: '#FF8C42',
  menuComplete: '#4ECDC4',
  scheduleInProgress: '#5B9BD5',
  confirmed: '#9B59B6',
  
  // Text
  textPrimary: '#1A1A1A',
  textSecondary: '#666666',
  textTertiary: '#999999',
  
  // UI
  primaryAction: '#FF8C42',
  unread: '#FF0000',
};
```

### 6.2 컴포넌트 구조

```
App
├── Navigation (하단 탭)
│   ├── RoomListScreen
│   │   ├── RoomCard (개선됨)
│   │   ├── TabFilter (진행중/완료)
│   │   └── FAB (새 약속 만들기)
│   ├── FriendsScreen
│   ├── ProfileScreen
│   └── NotificationsScreen (선택)
├── RoomDetailScreen
│   ├── RoomHeader (상태 배지)
│   ├── TabNavigation (채팅/메뉴/일정)
│   ├── ChatTab (개선됨)
│   ├── MenuTab (개선됨)
│   └── ScheduleTab (개선됨)
└── BottomSheets
    ├── CreateRoomSheet
    ├── DutchPaySheet
    └── ProfileEditSheet
```

### 6.3 스타일링 원칙

**React Native**:
- `paddingHorizontal: 16`, `paddingVertical: 16` (기본 여백)
- `borderRadius: 16` (카드), `borderRadius: 8` (버튼)
- `shadowColor`, `shadowOffset`, `shadowOpacity` (그림자)
- `flex: 1` 및 `flexGrow` 활용

**반응형**:
- 모든 텍스트는 `fontSize` 비율로 조정
- 카드 너비: 화면 너비 - 32px (양옆 16px 여백)

## 8. 성공 기준

- ✓ 약속 카드에서 상태를 한눈에 파악 가능
